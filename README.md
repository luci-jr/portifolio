## 🏛️ Destaques de Engenharia & Design System

Este projeto é uma demonstração de engenharia aplicada, micro-interações refinadas e arquitetura moderna:

- **Identidade Visual Âmbar Gold Unificada:** Paleta inspirada em monitores fósforo âmbar industriais e estética cyberpunk (`#f59e0b` / `#fbbf24`), com consistência absoluta no Modo Escuro e Claro.
- **Arquitetura Reativa (Angular 21 & Signals):** O chaveamento de modos altera dinamicamente todo o tema visual, paleta de cores, telemetria e estados em tempo real.
- **Hero Otimizado & Tipografia Balanceada:** Título de impacto com `text-wrap: balance` e prevenção de quebra de pontuação órfã via `.nowrap-end`.
- **Badge de Papel Técnico Flutuante:** Pílula com indicador de status (`● DESENVOLVEDOR BACK-END`) e micro-animação orgânica contínua `role-badge-float`.
- **Glassmorphism Paritário (Dark & Light Mode):** Camadas translúcidas em vidro fosco (`backdrop-filter: blur(12px)`), reflexo especular e iluminação sutil de néon âmbar.
- **Carrossel Infinito de Tecnologias (*Tech Marquee Ticker*):** Fita horizontal em CSS contínuo a 60 FPS com 27 tecnologias em rotação perpétua, com ícones externos em `public/icons/` e `icons/`.
- **Barra Lateral Retrátil Cyberpunk (Estilo iPortfolio):** Navegação vertical offcanvas com avatar iluminado, status online, redes sociais e âncoras para todas as seções (Início, Minha História, Vitrine, Tecnologias & Ferramentas, Especialidades e Contato).
- **Trilha Sonora Ambiente (*Warm Ambient Pad*):** Engine `ImmersiveAmbientAudioEngine` com progressão harmônica (Cmaj9 → Am9 → Fmaj9 → Gadd9), sinos suaves e botão de controle com nota musical + barra de corte CSS.
- **Controles Flutuantes Ergonômicos:** Alternância de Modo Escuro/Claro e efeito Scanlines CRT no canto inferior direito.
- **Telemetria Serverless em Go Nativo:** Função serverless em Go (`/api/status`) respondendo na edge da Vercel com métricas reais de latência e localização regional.
- **WebAssembly em Produção:** Integração com jogos compilados de Go para WASM (*Égua Mano Gamer*), rodando nativamente no navegador a 60 FPS.

## 🛠️ Execução e Desenvolvimento Local

O projeto conta com arquitetura dupla (SPA Angular 21 + visualização estática nativa):

### 1. Ambiente Angular (Recomendado)
```bash
# Instalar dependências
npm install

# Validar tipagem estática do TypeScript
npx tsc --noEmit

# Iniciar servidor de desenvolvimento
npm start
# ou
npx ng serve
```
Acesse: `http://localhost:4200`

### 2. Ambiente Vanilla (Five Server / Live Server)
Execute qualquer servidor HTTP estático na raiz do repositório:
```bash
npx five-server .
```
Acesse: `http://127.0.0.1:5500/index.html`
